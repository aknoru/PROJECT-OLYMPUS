# Tool and Resource Index

## Purpose

Index existing templates, tools, resources, standards, courses, books, papers, formulas, and reference tables.

## Scope

This appendix covers repository-native templates, software and hardware tool references, resource directories, reference indexes, and selection boundaries. It indexes and summarizes existing
material; it does not replace the owning document or create new implementation
requirements.

## Usage

Choose the artifact type or reference class, follow the canonical index, and verify current tool, license, version, and safety requirements before use.
