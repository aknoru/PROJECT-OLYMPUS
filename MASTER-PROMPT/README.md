# MASTER-PROMPT

## Purpose

This directory contains the **OLYMPUS Orchestrator v4** — the master AI operating
specification that governs how Project Olympus is autonomously analysed, documented,
and improved.

## Contents

| File | Description |
|------|-------------|
| [ORCHESTRATOR.MD](ORCHESTRATOR.MD) | OLYMPUS v4 complete specification — 8 Parts, 90 Sections |

## Orchestrator Summary

The ORCHESTRATOR defines:

- **Identity and Mission** — what OLYMPUS is and what it must achieve
- **Operating Principles** — 8 inviolable engineering principles
- **Global Rules** — 7 absolute constraints (never fabricate, never destroy knowledge, etc.)
- **Repository Intelligence Engine** — discovery, classification, knowledge graph
- **Documentation & IA Engine** — README standards, navigation, cross-linking
- **Knowledge Engineering Engine** — curricula, learning paths, assessments
- **Project & Portfolio Engine** — project lifecycle, evidence, portfolio
- **Automation & Governance Engine** — CI/CD, quality gates, self-healing
- **AI Self-Optimisation Engine** — multi-agent reasoning, priority matrix
- **Enterprise Knowledge Platform** — analytics, search, competency framework

## How to Use

When prompting an AI agent to improve this repository, provide the full
content of `ORCHESTRATOR.MD` as the system prompt or leading context.
The orchestrator is designed to be self-contained and self-explanatory.
