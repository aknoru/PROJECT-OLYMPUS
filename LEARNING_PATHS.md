# Learning Paths

> **Generated by:** OLYMPUS Orchestrator v4 — Part IV, Section 30
> **Purpose:** Provide sequenced, dependency-aware learning journeys from beginner to capstone for each engineering domain and career goal.

---

## How to Use This Document

1. Identify your **goal** from the Goal Paths section below.
2. Check your **prerequisites** — complete any missing foundations first.
3. Follow the **sequence** strictly — later modules depend on earlier ones.
4. Complete **projects and labs** at each milestone before advancing.
5. Use **assessments** to validate competency before moving on.

## Path 1 — GATE ECE Preparation

**Goal:** Score in top percentile on GATE Electronics & Communication Engineering
**Duration:** ~6 months (Operation Renaissance Phase 1–4)
**Difficulty:** Advanced
**Prerequisites:** B.Tech ECE Year 1–2 foundations

```
Phase 1 — Foundations (Weeks 1–8)
├── Engineering Mathematics      [02-engineering-foundations/01-engineering-mathematics/]
├── Network Theory               [02-engineering-foundations/02-network-theory/]
├── Signals & Systems            [02-engineering-foundations/03-signals-and-systems/]
└── Electronic Devices           [02-engineering-foundations/04-electronic-devices/]
        ↓
Phase 2 — Core Engineering (Weeks 9–18)
├── Analog Circuits              [02-engineering-foundations/05-analog-circuits/]
├── Digital Logic                [02-engineering-foundations/06-digital-logic/]
├── Control Systems              [02-engineering-foundations/07-control-systems/]
├── Communications               [02-engineering-foundations/08-communications/]
└── Electromagnetics             [02-engineering-foundations/09-electromagnetics/]
        ↓
Phase 3 — Computing (Weeks 19–26)
├── Programming & DSA            [02-engineering-foundations/10-programming-and-data-structures/]
└── Probability & Statistics     [02-engineering-foundations/11-probability-and-statistics/]
        ↓
Phase 4 — Practice & Mock Tests (Weeks 27–28)
└── Engineering Laboratory       [02-engineering-foundations/12-engineering-laboratory/]
```

**Milestones:**
- Week 4: Mathematics diagnostic score ≥ 70%
- Week 8: Signals & Systems problems solved ≥ 150
- Week 16: Mock GATE score ≥ 45 marks
- Week 24: Mock GATE score ≥ 55 marks
- Week 28: Release-ready portfolio of solved PYQs

## Path 2 — FPGA & Digital Design Engineer

**Goal:** Design and verify synthesisable RTL for FPGA targets
**Duration:** ~4 months
**Difficulty:** Advanced
**Prerequisites:** Digital Logic, basic programming

```
Level 1 — HDL Fundamentals
├── HDL Foundations (Verilog / VHDL)   [03-fpga-and-digital-design/01-hdl-foundations/]
└── Combinational Design               [03-fpga-and-digital-design/02-combinational-design/]
        ↓
Level 2 — Sequential & Verification
├── Sequential Design (FSMs, pipelines) [03-fpga-and-digital-design/03-sequential-design/]
└── Verification (testbench, simulation) [03-fpga-and-digital-design/04-verification/]
        ↓
Level 3 — Implementation
├── Timing & Clock Domain Crossing     [03-fpga-and-digital-design/05-timing-and-cdc/]
└── Synthesis & Implementation         [03-fpga-and-digital-design/06-synthesis-and-implementation/]
        ↓
Level 4 — Advanced
├── FPGA Interfaces (AXI, PCIe, DDR)  [03-fpga-and-digital-design/07-fpga-interfaces/]
└── DSP on FPGA (FFT, filters, FIR)   [03-fpga-and-digital-design/08-dsp-on-fpga/]
        ↓
Capstone
└── FPGA Capstone Project              [03-fpga-and-digital-design/09-capstone/]
```

**Milestones:**
- L1: Implement and simulate a 4-bit ALU in Verilog
- L2: Design and verify a 3-state FSM with formal properties
- L3: Meet timing closure at 100 MHz on target FPGA
- L4: Implement a streaming FIR filter via AXI-Stream
- Capstone: Portfolio-ready FPGA project with documentation

## Path 3 — Embedded Systems Engineer

**Goal:** Write production-quality firmware for ARM Cortex-M microcontrollers
**Duration:** ~5 months
**Difficulty:** Advanced
**Prerequisites:** C programming, digital electronics basics

```
Level 1 — C Mastery
└── C Foundations (pointers, memory, MISRA) [04-embedded-systems/01-c-foundations/]
        ↓
Level 2 — Hardware Abstraction
├── Microcontroller Architecture (ARM)  [04-embedded-systems/02-microcontroller-architecture/]
└── Peripherals & Drivers (GPIO, ADC)   [04-embedded-systems/03-peripherals-and-drivers/]
        ↓
Level 3 — Real-Time
├── Interrupts & Timers                 [04-embedded-systems/04-interrupts-and-timers/]
└── Communication Protocols (SPI/I2C/UART/CAN) [04-embedded-systems/05-communication-protocols/]
        ↓
Level 4 — Operating System
└── RTOS (FreeRTOS / Zephyr)           [04-embedded-systems/06-rtos/]
        ↓
Level 5 — Professional
├── Debugging & Testing (JTAG, unit)   [04-embedded-systems/07-debugging-and-testing/]
└── Power, Reliability & Security      [04-embedded-systems/08-power-reliability-security/]
        ↓
Capstone
└── Embedded Systems Capstone          [04-embedded-systems/09-capstone/]
```

**Milestones:**
- L1: Implement malloc/free from scratch; pass MISRA C lint
- L2: Blink LED via register-level GPIO (no HAL)
- L3: SPI sensor driver with interrupt-driven receive
- L4: Two-task FreeRTOS application with semaphore
- L5: Unit-tested module with >80% branch coverage
- Capstone: End-to-end embedded product with datasheet
