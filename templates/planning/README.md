# Planning Templates

> **Canonical location:** `templates/planning/`  
> These templates standardize campaign planning, phase gates, weekly review meetings, and daily execution blocks across Project Olympus.

---

## Available Planning Templates

| Template File | Focus Area | Usage |
|---------------|------------|-------|
| [`campaign-plan.md`](campaign-plan.md) | 184-Day Master Campaign | Defines Executive Decision, Baseline, 5-Phase Sequence, Priority Architecture, and Control Rules |
| [`annual-plan.md`](annual-plan.md) | Long-Horizon Strategy | Annual goals, quarterly milestones, capacity budgeting |
| [`phase-plan.md`](phase-plan.md) | Phase Gate Definition | Entrance criteria, specific phase deliverables, and exit gates |
| [`monthly-plan.md`](monthly-plan.md) | Monthly Milestones | 4-week Sprint targets, project milestones, and review dates |
| [`weekly-plan.md`](weekly-plan.md) | Weekly Control System | 4 outcomes (health, tech, career, maintenance), Sunday control review |
| [`daily-plan.md`](daily-plan.md) | Daily Anchors | Primary block (90m), secondary block (60m), maintenance block (30m) |
