# docs/javascripts

## Purpose

Contains custom JavaScript files loaded by the MkDocs Material documentation
site. These scripts extend the browser-side behaviour of the generated site
without modifying the MkDocs Material theme source.

## Usage

Files placed here are referenced from `mkdocs.yml` under the `extra_javascript`
key. They are injected into every generated page.
