# Architecture Decision Records

Architecture decisions are indexed in the
[ADR directory](../governance/decisions/README.md). Proposed records do not
authorize implementation until approved.

## Change Rule

Any structural change requires context, considered options, consequences,
migration impact, approval, and validation evidence.
