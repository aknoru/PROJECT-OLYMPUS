## Recovery Route

When normal execution is no longer credible:

1. Stop adding commitments.
2. Assess capacity, safety, deadlines, and essential obligations.
3. Select the smallest viable operating mode.
4. Record deferred work explicitly.
5. Follow the canonical [Recovery System](../01-operation-renaissance/14-recovery-system/README.md).
6. Return through a reviewed re-entry plan rather than hidden schedule compression.
