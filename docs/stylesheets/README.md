# docs/stylesheets

## Purpose

Contains custom CSS files loaded by the MkDocs Material documentation site.
These stylesheets extend or override the default Material theme styles to match
the Project Olympus visual identity.

## Usage

Files placed here are referenced from `mkdocs.yml` under the `extra_css` key.
They are linked on every generated page after the theme CSS.
